# 从使用到理解

这是一门给学生和开发者的 Codex 实践课。你只需要基本的编程、终端和 Git 知识。我们从一个任务清单程序开始，先完成有验收标准的小改动，再沿着实际行为深入公开源码与最小实验。

## 你会带走什么

完成课程后，你应该能够为任务写出可检查的要求，让 Codex 阅读现有项目并实施修改；用测试和差异审查判断结果；解释指令、工具、上下文和执行权限各自解决的问题；最后把可重复的步骤接入脚本与本地工具。

贯穿案例是 **Taskboard**：一个使用 JSON 存储的 Python 命令行任务清单。它足够小，可以完整阅读；又有持久化、兼容性、异常输入和原子写入等真实约束。交付物包含已完成的参考实现，以及供你从零完成标签过滤功能的练习起点。

## 怎么判断自己学会了

“命令运行成功”只是起点。每一章都要求你保留一种证据：任务契约、事件、测试结果、差异、拒绝原因或结构化输出。能从证据推出结论，并指出尚未验证的地方，才算完成。

你可以在章节末尾标记学习进度。进度仅保存在当前浏览器，不上传服务端。语言切换保留当前章节，中英文共享这份进度。

## 三种证据，不混用

- **官方实现**：固定到 Codex CLI `0.155.1` 的公开源码与官方文档。它说明产品实现和接口。
- **观察到的行为**：本地实际执行命令得到的输出。它只对报告中的环境与运行成立。
- **教学简化**：本仓库的 Python 模型和浏览器交互。它们帮助拆解机制，不是 Codex 的 Python 重写，也不是 OS 沙箱。

不需要 Key 也能运行全部离线实验、MCP 协议演示与网站。真实模型实验单独开启，需要可用的认证与联网条件；离线测试通过不意味着模型测试通过。具体证据见[验收记录](acceptance.md)。

## 从这里开始

运行[快速开始](quickstart.md)中的命令，然后进入第一个真实任务。需要排查环境时，查看[实验指南](labs.md)。准备贡献时，先阅读[贡献约定](contributing.md)和[来源与版本](sources.md)。

本项目为独立教学作品，与 OpenAI 官方产品没有隶属关系。CLI 是主线；桌面端章节只讨论用户可观察的操作对应关系。
